# Literature Review Assets

This folder contains a lightweight PRISMA-inspired rapid SLR workflow tailored for this semester thesis.

## Files

- `PRISMA_PROTOCOL.md`: protocol (scope, databases, queries, inclusion/exclusion, extraction + appraisal)
- `PRISMA_FLOW.md`: PRISMA flow diagram template (fill in counts)
- `screening_log.csv`: title/abstract + full-text screening log template
- `extraction_table.csv`: data extraction template for included peer-reviewed studies

## Intended use

1. Run the searches (2015–present) using the protocol.
2. Deduplicate records in your reference manager.
3. Track decisions in `screening_log.csv`.
4. Extract key details into `extraction_table.csv`.
5. Copy final counts into `PRISMA_FLOW.md` and summarize in Chapter 2.
