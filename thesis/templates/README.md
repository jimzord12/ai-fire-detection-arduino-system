# Thesis Templates

These are simple Markdown templates for drafting thesis content.

## What’s included

- A section/chapter/thesis scaffold using **numbered headings**.
- Each **subsection** includes:
  - a **References** block formatted in IEEE style (numbered `[1]`, `[2]`, ...)
  - an optional **Glossary** block for terms introduced in that subsection

## Templates

- `SECTION_TEMPLATE.md`: one section with multiple subsections
- `CHAPTER_TEMPLATE.md`: one chapter containing multiple sections/subsections
- `THESIS_TEMPLATE.md`: full thesis scaffold (chapters → sections → subsections)

## How to use

1. Copy the relevant template.
2. Replace placeholders like `<SECTION_INDEX>` / `<SECTION_TITLE>`.
3. For each subsection, add:
   - content
   - IEEE-style References
   - Glossary (only if needed)
